# Telefonbuch in C

Ein einfaches Telefonbuch-Programm, das ich im Rahmen meines C-Lernprozesses entwickelt habe.

## Funktionen

- Telefonnummern anzeigen
- Neue Telefonnummern hinzufügen

## Technologien

- Programmiersprache: C
- Standardbibliotheken: `stdio.h`, `string.h`

Mit diesem Projekt übe ich:

- Funktionen und Funktionsparameter
- Zweidimensionale Arrays
- Strings und Zeichenketten
- Benutzereingaben mit `scanf`
- Umgang mit Git und GitHub
